常见问题

下载前，可能想知道。

iTools 可以免费使用吗？＋

可以。iTools 目前面向所有个人用户免费提供下载与使用。

支持哪些系统？＋

当前正式版面向 Windows 11 64 位系统，并依赖系统自带的 WebView2 运行环境。

如何获取后续更新？＋

iTools 会在后台安静地检查正式版本，发现新版后可在应用内安装。

搜索内容会被上传吗？＋

不会。应用与文件搜索、快捷启动和本地工具都在你的电脑上完成。

不会编程，也能创建插件吗？＋

可以。连接支持 MCP 的 AI 编程助手后，只要描述工具用途，AI 就能按 iTools 规范创建、运行并调试插件。
