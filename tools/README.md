# 开发工装（不随安装包分发）

这个目录放的是**开发/验收用的东西**，与 `plugins/` 有一条硬边界：

`src-tauri/tauri.conf.json` 的 `bundle.resources` 把 `../plugins` **整个打进安装包**并在用户
首次启动时播种到他的插件根。所以凡是不该出现在用户机器上的插件，一律不能放 `plugins/`。

## `apitest/` —— 插件能力真机自检

它声明了**全部 20 项高危权限**，并带 `background` + `mainPush`（会随 iTools 启动自动后台跑）。
放进 `plugins/` 就等于把一个全权限、开机自跑的插件发给每一位用户——所以它在这里。

用法见 [`doc/插件系统/真机验收报告.md`](../doc/插件系统/真机验收报告.md) 第二节：
在「管理中心 → 开发者」里把本目录添加为调试插件目录，或直接拷进 `dev-plugins/`
（该目录已在 `.gitignore` 里，同样不随包），再按报告里的办法预授权即可。
