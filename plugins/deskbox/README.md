# DeskBox · 笔记 / 待办 / 密码

一个 iTools 插件，把三样每天都要用的小工具装进同一个面板：**树形笔记（可加密上锁）**、**待办清单**、**加密密码管家**。全部数据存在本机，支持搜索，界面自适应深浅色。

## 功能

### 📝 笔记
- **树结构**：文件夹 / 笔记任意嵌套，可展开折叠；**拖拽**移动与重排（拖到文件夹上=移入，拖到笔记上=排在其后，拖到空白=移到根）。
- **加密上锁**：任意一条笔记可用主密码加密（🔒），正文以 AES‑GCM 加密后存储，未解锁时只显示标题、看不到内容。
- **Markdown**：正文支持 Markdown，👁 可切换预览（`#` 标题、`**粗**`、`` `代码` ``、列表、引用、``` 代码块、`[链接](http…)`）。链接用系统浏览器打开。
- 双击标题重命名；创建/修改时间显示。

### ✓ 待办
- 回车快速添加，勾选完成，双击编辑，**拖拽排序**。
- 过滤：全部 / 进行中 / 已完成；一键清除已完成。

### 🔑 密码
- 首次使用设置**主密码**，之后所有密码条目以 AES‑GCM 加密存储。
- 每条：名称 / 用户名 / 网址 / 密码 / 加密备注；一键复制、显示切换、打开网址。
- 内置**强密码生成器**（长度 + 大小写/数字/符号，基于 `crypto.getRandomValues`）。

### 🔎 搜索
顶栏搜索框随当前分区实时过滤：笔记（标题 + 已解锁正文）、待办（文本）、密码（名称/用户名/网址）。

## 安全模型

- 一个**主密码** → PBKDF2(SHA‑256, 60 万次) 派生出 AES‑GCM‑256 主密钥。
- 主密钥**只存在内存里**，随会话解锁一次；主密码**从不落盘**——磁盘上只有随机盐 + 一个校验块。
- 同一把主密钥既加密密码库，也加密上锁的笔记。顶栏 🔒 / 设置里可随时“立即锁定”清除内存中的密钥。
- 密码条目的**密码与备注字段加密**；名称/用户名/网址为明文以便搜索与列表展示。
- 忘记主密码**无法找回**（这正是加密的意义）。请设置好记的长口令。

> 依赖浏览器 Web Crypto（`crypto.subtle`）。若运行环境不提供，会提示并停用加密相关功能，其余功能照常。

## 安装

1. 把整个 `deskbox/` 目录放进 iTools 插件目录：
   - 开发/项目内：iTools 项目根的 `plugins/`；
   - 安装版：`%LOCALAPPDATA%\iTools\plugins\`；
   - 或设环境变量 `ITOOLS_PLUGINS_DIR` 指向的目录。
2. iTools **托盘图标 →「重新加载插件」**（无需重启）。
3. 主搜索栏输入上面任一关键词 → 回车打开面板。

> 本插件不需要任何高危权限（无 `network` / `runCommand`），纯本地运行。

## 关于云端同步（未来）

现在所有数据通过一个薄封装 `Store` 读写 iTools 的本地 `db`。等 iTools 的**远程数据存储 API** 就绪后，只需在 `Store`（`index.html` 顶部）里加一个 remote 后端并做本地↔远程同步，上层业务代码无需改动。设置里已有“云端同步 · 即将支持”的占位。

## 快捷键

`Esc` 收起面板（或先关弹窗）· `Ctrl+F` 聚焦搜索 · `Ctrl+P` 笔记预览/编辑切换 · 待办输入框 `Enter` 添加。
